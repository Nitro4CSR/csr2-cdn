# 0.7.0.dev17: crew-member profile fields (experimental)

Dev16's integrated Season 277 Prestige Cup live test succeeded and returned 21 standings entries. It did **not** recheck crew roster profile fields. The last verified read of own-crew members returned 29 roster entries, but no field-by-field live coverage report was collected.

## Source and mapping

CSR2 6.8.0 exposes read-only `crews/checkUserCrew` followed by `crews/viewMembers`. The existing native `PlayerCrewMember.FromJSONList` dictionary/array decoders name the fields `name`, `rp`, `level`; the compact native records contain RP and level in both supported layouts.

Dev17 promotes the following previously opaque roster values:

| Public `CrewMember` property | Known wire fields | Interpretation |
| --- | --- | --- |
| `nickname` | `name`, `nickname`, `nickName`, `playerName`, `player_name`, `displayName`, `display_name` | Display name; `name` preserved for compatibility |
| `crew_rp` | `crewRP`, `crew_rp`, `crewRp`, `rp` | RP number supplied by the **crew member** record; seasonal-vs-lifetime interpretation must be checked in-game |
| `player_rank` | `level`, `playerLevel`, `player_level`, `playerRank` | Player level/rank; not a leaderboard position or crew roster position |

Values not present or not coercible to integer remain `None`, including invalid booleans. `0` is a valid reported RP/level value. The ambiguous standalone `rank` field is **not** treated as player level. Existing positional `CrewMember` construction remains compatible.

Opaque response extras stay in memory and are not printed by the CLI serializer. Normal live validation shows only member counts, including `nickname_populated`, `crew_rp_populated`, and `player_rank_populated`; it prints no identities or raw record values.

## Authorized field-coverage check

```powershell
python -m pip install .\csr2_cdn-0.7.0.dev17-py3-none-any.whl
python -m csr2cdn.live_validation --execute --crew-only
```

The caller enters their PlayerID through the hidden prompt. `--crew-only` retrieves own-crew membership and the roster; it skips event metadata, Showdown, Prestige Cup, and legacy Leagues requests. Share the **sanitized count report only**, not the raw crew roster or account identifiers.

To inspect the actual profile values locally for a comparison against the game:

```powershell
csr2cdn services --execute crew
```

This command intentionally prints public crew-member fields to the user's local terminal; do **not** paste that response publicly without crew members' consent.

## Validation gates

Offline source and wheel tests verify the mapping for native-style dictionary and compact list records, privacy of the live diagnostics, and the crew-only route. An authorized production test must establish field coverage and whether the `rp` number equals the in-game **current-season Crew RP** value. The final 0.7.0 release remains blocked on Prestige score/rank verification, pagination, live cached season and identity-mode confirmation, and cross-platform CI.
