# Dev35 — Offline structural hypotheses from the Dev34 private rim export

**Scope:** locally provided public-source cache-derived data only. No new public CDN requests are necessary; there are no authenticated game reads. This is an investigation build, **not** a production wheel-name resolver.

## Why this exists

The user's Dev30 online capture and offline replay established 480 primary rim records, 27 distinct `CompatibleCars` strings, and **zero exact, casefolded or punctuation-insensitive overlaps** among three selected native string namespaces. Separately, `CarNames` contained 138 entries with four repeats and `DefaultRim` contained 134 entries. These aggregates do not establish a positional pairing or eligibility.

Dev34 added an opt-in private local JSON export of the actual native rim strings (not included in the distribution). Dev35 adds a separate offline **counts-only** analysis of that file, designed to test a few explicitly narrow hypotheses without publishing original values.

## Use

First, in the environment that already holds the validated source cache, create the Dev34/Dev35 private local export **if it does not already exist**:

```sh
python -m csr2cdn.dev30_public_source_replay \
  --replay-dir ./public-source-cache \
  --baseline-audit public-source-audit.json \
  --output dev35-offline-replay.json \
  --private-rim-fields-output dev35-private-rim-fields.json
```

Both `--output` and `--private-rim-fields-output` require new filenames. Then run the **entirely offline** Dev35 analyzer:

```sh
python -m csr2cdn.dev35_private_rim_analysis \
  --private-rim-fields dev35-private-rim-fields.json \
  --baseline-replay dev35-offline-replay.json \
  --output dev35-redacted-structure.json
```

The second command does not load or contact the CDN; `--baseline-replay` checks the fingerprint from the private export against the **independently created** replay report. Omitting this comparison is allowed but the report explicitly notes that no independent replay fingerprint was compared. The private source-export JSON and original source bundles must remain private; **the redacted `dev35-redacted-structure.json` is the report to share**.

## What the output measures

- Rim source IDs: count of distinct and duplicated source integer IDs; no integers exported.
- Rim source names: duplicate-name counts; no names exported.
- Root `CarNames`: entry/distinct counts, repeated strings in separate (nonadjacent) runs, adjacent identical pairs, count after collapsing only adjacent duplicate runs.
- Root `DefaultRim`: distinct and entry counts, and whether either *cardinality-only* car-name hypothesis happens to match the number of defaults.
- For each root name, root default, and compatible-car string namespace: count of **strictly** decimal or `0x` hexadecimal string tokens coinciding with an existing rim source integer. This excludes bare hexadecimal guesses, encoded bytes, hashes, transformed names, etc.
- Direct literal overlaps with primary rim names and the independent root list, without deriving links or eligibility.

Even if the 138/134 discrepancy is completely explained by adjacent duplicate runs, that would be a **structural observation only**. It would not establish `CarNames[i] -> DefaultRim[i]`, nor which string namespace can resolve roster wheel names. Numeric representation equality is likewise not mapping evidence.

## Integrity, privacy and testing

The input must satisfy the Dev34 opt-in schema and bounded shape checks, with no player/roster data markers, and optionally must have the SHA-256 of a separately saved offline replay. Read-only input and exclusive output creation prevent unintentional overwrites; errors do not echo source strings or paths. The report includes counts, booleans, a source SHA-256, zero network/gameplay counters and explicit non-promotion flags.

Dev35 regression tests use **synthetic native bundles** and malformed fixtures. The real 480-record source bundle and private export were **not provided** here, so no new real-source structural counts are claimed. To measure the real source, run the commands above and share only the redacted report.

Existing TNR decoders, strict loaders, source-ID mappings, wheel semantics and game-facing logic remain unchanged. The historical ten paint and one interior misses remain unknown without a roster snapshot.
