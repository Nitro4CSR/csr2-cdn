# 0.7.0.dev14 — dedicated SpecialLadderEvents investigation

This investigation addresses a structural omission after dev11–13 repeatedly
produced zero Prestige candidates, despite successfully loading Showdown,
CupInvitationalRaceSeries, CareerRaceEvents and InvitationalRaceSeries.

## Client evidence

- In the supplied 6.8.0 IL2CPP metadata, `SpecialLadderEvents` has a
  `LadderEvents` field (`RaceEventTopLevelCategory`) that holds
  `RaceEventGroups`.
- `RaceEventDatabase.SetAndProcessSpecialLadderRaceEventData` (RVA
  `0x32f3b84`) invokes `ProcessSpecialLadderRaceEventData` (`0x32f33fc`).
- `ProcessSpecialLadderRaceEventData` fetches the ladder category, iterates
  its groups, adds them to `RaceEventGroupDict` via `0x3313c10` and calls
  `RaceEventGroup.ProcessEvents` (`0x32f4154`).
- `SpecialLadderEventsDatabase.ReadSpecialLadderEvents` (`0x342bc4c`)
  constructs the underlying metadata object. The configured name appears
  in the package's block ID catalogue.

This is a **separate client registration source**. It is not evidence that
Prestige Cup necessarily resides in this category. Live source presence and
Prestige classification have not yet been established.

## Implemented

- Request `SpecialLadderEvents` in the existing authorized metadata lookup.
- Traverse only its `LadderEvents` hierarchy; do not treat all special
  ladders as Prestige.
- Preserve existing native `Silver_Prestige` telemetry gate.
- Report anonymized source counts, including whether the serialized `LadderEvents.RaceEventGroups`
  list exists and whether those groups carry leaderboard attachments but do not pass classification.
- Never fabricate a Prestige leaderboard name or treat missing event data as
  proof that no game event exists.

## Key next observation

If `special_ladder_groups` or the attached-leaderboard count is nonzero,
we can examine the in-game registration/classification chain more narrowly
without logging raw event records. If the source is unavailable or empty,
we must trace the next upstream category or non-metadata event generation.

This build has **not** been production-tested. Final 0.7.0 publication
remains blocked on an authenticated Prestige read and the required regression
and release checks.
