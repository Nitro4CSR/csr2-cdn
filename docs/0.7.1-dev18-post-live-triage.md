## Run the offline count triage

```bash
python -m csr2cdn.bulk_gap_triage bulk-live-report.json
```

The file must be an existing, locally saved, sanitized Dev17 JSON report, not
this Markdown report. The command has a bounded 2 MiB input and **zero** network
operations. It strips unrecognized data from output rather than reprinting
source values. It does not accept a player ID, reveal raw cosmetic codes, or
perform additional leaderboard reads. With no filename, the command simply
prints a dry-run description. It refuses invalid counts, unexpected slots,
and values exceeding the roster population.
