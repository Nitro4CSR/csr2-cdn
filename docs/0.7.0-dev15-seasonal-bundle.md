# Seasonal Prestige car metadata (development finding)

The CSR2 6.8.0 season-numbered type-47 ASTC bundles are UnityFS archives containing JSON TextAssets. The 279 example verifies that seasonal metadata is wrapped in an outer `"279"` object with `ShouldLoadIntoMetadata: true`. It contains `CrewLeaderboardRewardDefinitions -> SeasonalRewardCars -> 279 -> PrestigeCupCar`, one EventSchedule record, and cup/invitational series records. It does **not** contain a Prestige group or leaderboard attachment.

The previous runtime catalogue extracted Showdown/race groups, event schedules, leaderboard definitions, and RaceSeries, but silently discarded `SeasonalRewardCars`. The dev15 extractor preserves the mapping under `_RuntimeSeasonalRewardCars`, keyed by the exact serialized season; `seasonal_prestige_car(blocks, season)` returns the matching car without inferring the season from the local clock. Conflicting car definitions or malformed season identifiers fail closed. This is **not** an event-to-board resolver: the actual repeatable Prestige group and its leaderboard are still unconfirmed.

The uploaded example's gacha event starts in November 2026. It cannot establish current October Prestige leaderboard availability. A contemporaneous season ASTC bundle is needed to compare seasonal inputs, and native event-template processing remains to be reconstructed before public Prestige support can be claimed. Do not ship the supplied Unity bundle or raw event JSON in the Python distribution.
