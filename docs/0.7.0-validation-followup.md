# Follow-up to the 0.7.0.dev2 validation report

The supplied `VALIDATION_REPORT.md` establishes that metadata access worked
for the installed dev2 package, but no authenticated crew or leaderboard read
was performed. This is not a successful compatibility result for the proposed
0.7.0 features.

## Resolved in dev3 (offline only)

- Own-crew identification no longer requires an externally supplied `crewUID`.
  The library uses the game's distinct own-crew read and then the existing
  member-list read, with both response and URL identifier validation.
- The live runner now attempts this two-read sequence by default, even when
  Showdown discovery remains unresolved. `--skip-crew` disables it.
- `unresolved_board` causes a nonzero CLI exit status; an unresolved board
  should not count as a passed Showdown compatibility test.
- `ShowdownEventsContainer.RaceEventGroups` entries that contain
  `EventGroupName` and `ScheduleID` but no `id` are no longer discarded.
  `EventGroupName` is a candidate label, **not** an authoritative event ID.

## Reconciliation after dev5

Dev5 now resolves all four leaderboard inputs for the historical local
metadata sample. It does not establish a current live board. `Time_ActiveBetweenAny`
and `BasedOn_ScheduleID` are supported for the validated sample, but advanced
recurrence remains a distinct gap. Dev6 confirms that the standalone metadata
source can be incomplete because the client merges event metadata from asset
bundles; see `0.7.0-dev6-validation-review.md`.

## Still unresolved from the broader release plan

- Advanced recurring or player-dependent schedules remain unresolved where the
  necessary timing inputs are unavailable.
- `LeaderboardTemplateID` is not a resolved server board ID. Dev5 reconstructs
  the four-part ordinary leaderboard identifier when inputs exist, but real
  current-event discovery may require asset-bundle metadata outside the standalone blocks.
- Prestige Cup's event-specific leaderboard mapping and all game-service
  response contracts require live validation.
- A complete Windows/Linux supported-Python CI matrix, release tagging,
  GitHub distribution, and PyPI publication have not been performed.

The synthetic test suite is intended to prevent regressions; it is not
substitute evidence for these online contracts. No private event or player
record has been bundled in the package.
