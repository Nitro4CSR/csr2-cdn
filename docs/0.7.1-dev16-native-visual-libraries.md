## Evidence

All rows below were decoded offline from user-provided original CSR2 6.8.0
Android ASTC UnityFS bundles, checked against the included Unity serialized
type-tree fields. Version numbers are from the provided asset database, not
freshness guarantees for future game versions.

All 1,693 IDs are unique **inside each respective library**, including the
negative `CarWrapLibrary` IDs (e.g. `-125`). Identifiers are not globally
unique across different libraries; preserve the associated slot.

## Native details that matter

- Flags have both a short NameID such as `AF` and a human-readable
  CountryName such as `Afghanistan`. `.name` uses CountryName.
- Racing numbers contain NameID identifiers for numerals, not full font
  glyph representations. The library type tree contains `CarNumberType`.
- License plates have empty optional `LicensePlateType` values in some
  records, which are valid; NameID itself is still populated.
- Wraps use signed negative IDs, not paint IDs. These are standalone.
- Livery-set rows contain a separate `liveryID` and `liveryZoneID`. Their
  descriptive NameID is exposed, but there is no invented roster livery-set
  field or global `liveryID == liverySetID` equivalence.
- Livery zone sets have a LocalisationStringID and zone flag array; the
  source NameID is provided as the display candidate without substituting
  translations from unrelated tables.
- Tuner Stars rim records contain numeric IDs and NameIDs, sizes, brand,
  category, and compatible-car lists. The `CarNames` and `DefaultRim`
  arrays occur at the **library root**, not inside each `CarRim` record.
  The roster's `car_wheel_name` string is not assumed equal to rim `ID`.

## Attribute-first usage (offline)

```python
from csr2cdn import load_visual_libraries_unityfs

sources = load_visual_libraries_unityfs([
    "CarFlagLibrary.ASTC.532", "CarRacingNumberLibrary.ASTC.524",
    "CarLicensePlateLibrary.ASTC.580", "LiveryZonesSetLibrary.ASTC.670",
    "CarWrapLibrary.ASTC.677", "CarLiverySetLibrary.ASTC.661",
    "CarTunerStarsRimLibrary.ASTC.434",
])
car = snapshot.with_visuals(sources).members[0].vehicle
car.visuals.decal_flag.name
car.visuals.decal_number.name
car.visuals.decal_numberplate_style.name
car.visuals.livery_zones_set.name

sources.match(None, "wrap", -125).name     # Nugget (observed bundle)
sources.match(None, "tuner_rim", 1000001).name  # 14A (observed bundle)
sources.match(None, "livery_set", 0).name   # Ferrari 250 GTO Yellow Y
```

No automatic CDN/gameplay I/O, no bundled proprietary assets. Missing IDs
return unresolved names. Source SHA-256 fingerprints accompany decoded
records. Combined authorized gameplay validation, UI equality, potential
visual-library version drift and non-Android support remain future checks.
