# Dev21: source freshness and local ASTC inventory

## Motivation and observed evidence

The operator-authorized Dev17 run decoded 124 of 192 visual codes. Missing:
29 wheel strings; 24 decal-number/shape/zone colour fields; 9 paint IDs;
3 interior IDs; 3 caliper IDs. Existing real-source libraries contain 8,614
named records, but the historic Dev17 sanitized report does not include the
unmatched codes. Source-version comparisons cannot infer which of those exact
IDs are fixed until an explicit numeric-ID diagnostic is available.

## What Dev21 establishes

Given two **local** asset database files, `compare_visual_asset_databases` or
`python -m csr2cdn.visual_asset_refresh_cli` extracts exact Android ASTC entries
for all 12 decoded visual libraries. Version changes, removals and additions
are distinguished from unchanged versions and anomalous size changes under a
constant version. Optional local bundle checks require exact database-derived
filenames; return `missing`, `size_mismatch`, `unsafe_file`, or
`size_matches_unverified_content`. Symlinked bundles are not followed.
The default CLI invocation is a zero-network dry run; add `--show-urls` only
for candidate links extracted from the supplied database.

## How to reproduce offline

```bash
python -m csr2cdn.visual_asset_refresh_cli \
  --before-database asset_database_6_8_0_Release \
  --after-database asset_database_6_8_0_Release \
  --bundles-dir /path/to/12/original/ASTC/files
```

With the 6.8.0 index 33695 as both inputs, the report should show 12 unchanged
versions, and if the original files are present, 12 matching file sizes.
This is a **baseline self-check**, not evidence the CDN has no newer versions.
For actual freshness evidence, provide an independently retrieved later asset
database as the second input, then use the existing `visual_source_delta`
command to compare newly downloaded/decoded ASTC files before changing labels.

## Limitations / privacy

No service authentication, requests, game writes, player IDs, vehicle names,
or raw cosmetic identifiers are needed. Output may include only library names,
versions, byte sizes, and optional asset CDN URLs. The API never asserts that
matching file size proves authenticity. Wheel and colour joins, unknown model
semantics, additional offset pagination and official UI presentation remain
unverified; published v0.7.0 stays unchanged.
