# 0.7.1.dev22 — focused TNR/Tuner Stars visual probe

## Rationale

The October 18 combined crew read resolved 124/192 cosmetics and missed 29
wheel strings, 24 color/zone fields, 9 paints, 3 interiors and 3 calipers.
The local 6.8.0 asset database distinguishes the standard car libraries from
nine `CarTunerStars*Library` / `TunerStarsLiveryZonesSetLibrary` assets.
Model keys such as `Mazda_RX8TNR0_2008` establish only a useful cohort string,
**not proof that the Tuner Stars visual library is appropriate for that car.**

## Privacy and request budget

Default invocation uses **zero** HTTP requests. The opt-in `--execute` path
uses `crews/checkUserCrew` followed by `crews/viewMembers` once each, using
existing request signing. It performs no GCC reads, metadata downloads, save
operations or writes to game state. It prompts for the PlayerID only in an
interactive terminal; the ID is never included in reports. Do not upload raw
fixture JSON. Only a sanitized `--output` report needs to be shared.

## Prepare local source data

Use the already-downloaded `asset_database_6_8_0_Release` and the decoded
standard visual libraries. Offline planning does not download new libraries.
Tuner-specific visual library versions/URLs come from your local database,
not from guessed versions. The full set is included in the result as an asset
plan; only the Tuner Stars rim decoder has been verified at this point.

### Zero-network dry run

```bash
python -m csr2cdn.tnr_visual_probe
```

### Optional offline replay (only if you already have raw replies locally)

```bash
python -m csr2cdn.tnr_visual_probe \
  --asset-database asset_database_6_8_0_Release \
  --own-json own-private.json --members-json members-private.json \
  --visual-asset-bundle CarPaintLibrary.ASTC.1195 \
  --visual-asset-bundle CarInteriorLibrary.ASTC.1139 \
  --visual-asset-bundle CarCalliperLibrary.ASTC.1004
```

### Future one-round live probe (requires explicit authorization)

```bash
python -m csr2cdn.tnr_visual_probe --execute \
  --asset-database asset_database_6_8_0_Release \
  --visual-asset-bundle CarPaintLibrary.ASTC.1195 \

```

The script also accepts additional previously verified standard ASTC bundles
by repeating `--visual-asset-bundle`. It writes a **sanitized** report only,
refuses to overwrite an existing report, and never saves response bodies.
The optional `--show-unmatched-numeric-ids` outputs distinct numeric IDs and
occurrence counts without member or model associations. Do not enable it
unless sharing those codes is acceptable. Wheel strings remain excluded.

## Reading results

- `tnr_model_syntax` is a heuristic model-key cohort, not game semantics.
- `other_or_unknown_model` is the comparison cohort.
- `resolved_in_standard_library` means the old exact standard-ID mapping exists.
- `unresolved` in the TNR cohort may point toward Tuner Stars-specific source
  libraries, but it does **not** establish a correct alternative match.
- `model_wheel_assets_found_members` only means model-prefixed wheel assets
  are listed in the asset database; no string-name join is claimed.
- `decal_number_*` color ID relationships remain unverified regardless of
  accidental numeric overlap with the standalone `CarColorLibrary`.
