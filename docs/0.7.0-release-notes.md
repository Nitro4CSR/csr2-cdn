# 0.7.0 release notes

Adds read-only crew and event services alongside the existing CDN, HUB,
metadata and dynamic snapshot APIs.

- Discover your crew and retrieve members, roles, player levels and seasonal contributions.
- Compare member contribution totals with the exact matched GCC crew score and rank.
- Resolve Showdown standings from the event name and current metadata.
- Read global and server-filtered crew Prestige standings, preserving server placements.
- Format Prestige race times exactly to six decimal places from integer microseconds.
- Inspect sanitized diagnostics and rehearse season resets without network access.

GCC scope is top ten plus five crews above/below your crew. Full pagination,
optional statistics and deeper vehicle data are deferred to 0.7.1. Season
rollover has synthetic coverage but has not been observed live. Prestige may
require explicit current season/car inputs; historical inputs are not defaults.

Install the `events` extra for event discovery. Service network access is opt-in.
No game-state changes or saved-game operations are included.

Publication approved by the owner on 2026-10-17 after final candidate CI passed.
