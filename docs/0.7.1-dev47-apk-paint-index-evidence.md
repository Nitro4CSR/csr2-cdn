# Dev47 — APK paint index versus paint ID (offline)

## Source and result

Analyzed CSR2 6.8.0 APK IL2CPP `global-metadata.dat` (version 31), original Dev36 public source-ID catalogue (database 34011), and an **optional private** cached Dev38-era 29-member roster. The report is `dev47-apk-paint-evidence.json` and contains only structural metadata and aggregate counts. No APK, native `.so`, private cache, roster identities, model identifiers, or individual roster paint values are bundled with Dev47.

- `CrewMemberCarInfo`: `CarPaintIndex` / `SetPaint(paint_index)` versus `CarInteriorID` and `CarCalliperID`.
- `SMPHostInfo`: `AppliedPaintIndex` versus `AppliedInteriorID` and `AppliedCalliperID`.
- `PlayerInfo`: `_paintIndex` versus `_interiorID` and `_calliperID`.
- `CarGarageInstance`: `AppliedPaintIndex` / `_OriginalPaintIndex` versus `AppliedInteriorID` / `AppliedCalliperID`.
- `CarVisuals`: `CarPaintIDs` and `current_paint_index`; both other cosmetic collections are named with `IDs`.
- Both `CarPaintLibrary` and `CarTNRPaintLibrary` declare `GetIDByIndex(index)` and `GetIndexByID(paintID)`.
- `ConfiguratorMenuScreen.ShouldShowDefaultPaintForCar`, `FtueDealershipCarsConfig.GetForceDefaultPaint` and `CarAftermarketCustomisationsManager.IncludeCustomisationDefaultsForCar` are present, but their **native bodies have not been analyzed**.

The optional cached roster reproduces 20 matching and nine absent paint occurrences in the DB 34011 source catalogue. Its coarse bins are eight zeros, one fifteen, 18 other values below 100, zero between 100 and 999,999, and two values in the million-range. Source-ID presence *alone* is not a verified vehicle eligibility relationship.

## Interpretation boundaries

The client clearly distinguishes index and ID concepts for paint, but method names and fields alone **cannot** establish which representation the server's `car_paint_id` uses. A per-car index is a plausible interpretation for value 15, and index 0 is a plausible default-selection state, but neither is proven. Million-range values in the same roster show that any universal interpretation must be tested especially carefully. The `0 => Transparent` display alias remains operator-approved only; it is not a native game-semantic conclusion.

This command is offline and requires **no authenticated requests**:

```bash
python -m csr2cdn.dev47_apk_paint_semantics \
  --apk CSR2_6.8.0.apk \
  --private-cache-zip endpoint-cache.zip \
  --source-catalog dev36-source-ids.json \
  --output dev47-apk-paint-evidence.json
```

Both `--private-cache-zip` and `--source-catalog` are optional (the latter requires the former). Keep the private cache local and uncommitted. The report never emits user identifiers, player/crew names, car model strings, or raw roster records. No production resolvers are modified.
