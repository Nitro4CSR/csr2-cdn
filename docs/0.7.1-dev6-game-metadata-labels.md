# Dev6 source direction and validation boundaries

## Correct sources

- **Game metadata blocks:** query the game's Metadata CDN, which serves
  independently refreshed blocks with per-block hashes. `MetadataCache.sync`
  can update them explicitly; local `MetadataCache.load` reads JSON offline.
  APK versions may be stale. APK SHA256 does not prove game labels.
- **Game car names:** source the game's car translation files, retaining
  independent `SHORT`, `MEDIUM`, `LONG`. Default `MEDIUM` is user-selectable
  via `--car-name-style` or `CarNameStyle`. Missing variants remain missing.
- **Visual-code names:** source the corresponding *visual-code libraries*
  (paint, wheels, etc), not a single guessed numeric ID dictionary. Preserve
  exact model/slot/code distinctions and the library name for provenance.
- The existing HUB `TextData/CarData.json` supplies community candidate tier,
  star and EV information. Its `DBName` is **not** a translated car label.
  HUB `Localisation/XX.json` concerns HUB user-interface strings and must not
  be silently substituted for the game's car translation files.

## Available code and what is not done

Existing API: `CDN.get_metadata`, `CDN.metadata_cache`, `MetadataBlock`,
`MetadataCache`. Dev6: `metadata_library_inventory` for selected offline
metadata blocks, plus `GameCarTranslations`, `GameVisualLibrary`,
`game_label_report`. `crew_bulk_validation` accepts local normalized manifest
paths and keeps identifiers and labels private unless `--show-members`.

**Pending:** inspect actual decoded current translation files and each
visual-code library to build schema-specific parsers. The normalized v1
exchange files are intentionally NOT claimed to be the game's wire format.
`CarPaintLibrary` is an asset-database example, not evidence that it is a
metadata block. No game online read was made, so source freshness and
coverage on live roster vehicles are pending. This is preparation for the
single operator-authorized bulk test and subsequent pruning round.

## Explicit optional CDN metadata sync example (not run)

```python
from csr2cdn import CDN
with CDN(zid="YOUR_OWN_ZID") as cdn:
    cache = cdn.metadata_cache("metadata_cache")
    cache.sync(["CarCustomizationParameters", "CarLiveriesMatrix", "CarPresets"])
```

This is a separate authenticated read, not part of the four game-service
requests or an offline test. `--metadata-cache-dir` never performs `sync`.
