# 0.7.0.dev16 — Native Prestige Cup template resolver (unreleased)

This developer build integrates source-backed CSR2 6.8.0 Prestige Cup work that was researched **after** dev15. It is not a verified release: **no authorized live standings response has been observed**.

## What changed

- Downloads the distinct type-46 `assets_client_metadata_special_ladder_events_database` ASTC asset from the current AssetDatabase, using its stored version, rather than guessing a URL or searching for season-numbered type-47 event groups.
- Decodes the actual binary `SpecialLadderEvents` TextAsset with structure and size checks, including the serialized `PRESTIGE_CHAMPIONSHIP_SILVER_LADDERS` group, 31 race entries, `EventFile=4`, season-specific car lookup, attached leaderboard, original July 2019 seven-day event window and 14-day repeat.
- Accepts both native `Silver_Prestige` and serialized `silver_prestige` telemetry when an actual group structure is present. A lone matching marker remains insufficient.
- Reproduces the game's normal timed-board name using the current crew-season input, the extracted Prestige car tier, the client race ID formatter, and the **actual `EventLeaderboards` definition** (requiring ranked entity Player, Best FastestHalfMileTime, and a known ranking order).
- Requires the selected season to have a corresponding `PrestigeCupCar` in decoded seasonal metadata. The optional local car JSON also cross-checks that key and extracts `BaseCarTier+1`.
- Refuses to produce a board ID when the binary template is missing/changed, selected season has no matching car, ranking definition is missing/unexpected, or the occurrence window is not active.

**Still manual for this live gate:** The current value of `GrandCrewChampionshipManager.get_seasonID_ThisSeason` and the client's car-tier record are not available from the downloaded repeatable template itself. For the first authorized validation, supply the known active season and your already-extracted car JSON. These are explicitly checked against the downloaded seasonal metadata. This is not yet fully automatic future-season discovery. A separate nonstandard event-leaderboard identity mode is also not verified on the active profile.

## Recommended read-only live test (Windows PowerShell)

Install the wheel plus the optional event decoder dependencies:

```powershell
python -m pip install .\csr2_cdn-0.7.0.dev16-py3-none-any.whl
python -m pip install "UnityPy>=1.20" "lz4>=4.0"
python -m csr2cdn.live_validation --execute --skip-crew --prestige-current --prestige-season 277 --prestige-car-json .\Porsche_Manthey911GT3RSRewardRecycled_2024.json
```

The active player supplies PlayerID through a non-echoing terminal prompt. No save-game operations are performed. The CLI reports sanitized source coverage and a standings count (or an error category), never the authenticated response body or player identifiers. A completely offline dry run omits `--execute` and reports zero network requests.

If you only have an independently verified car display tier, use `--prestige-car-tier 5` instead of `--prestige-car-json`, but the JSON provides the stronger identity cross-check.

## Python API

```python
from csr2cdn import CSR2Services

with CSR2Services('YOUR_PLAYER_ID', allow_network=True) as api:
    page = api.get_current_prestige_cup_leaderboard(
        season=277,
        prestige_car_tier=5,
        prestige_car_key='Porsche_Manthey911GT3RSRewardRecycled_2024',
    )
```

This should be attempted only after local metadata resolution confirms the input values. The current production board has **not** been verified, and the correct score/rank semantics and pagination still require the independent read-only live test.

## Diagnostics

The existing diagnostics include independent `binary_prestige_*` fields: template source configured, template load success/failure, attached leaderboard, supplied runtime inputs, resolution blocker and active resolved board count. Legacy metadata-group counts remain available. No raw template records are logged.

## Evidence and reproducibility

The development build was validated against the user-provided CSR2 6.8.0 special-ladder ASTC, Season 277 bundle, extracted Porsche car JSON, and `EventLeaderboards.meta` in a local offline cross-check. Those proprietary files are not bundled in the source archive. The derived standard timed-board ID was `evnt-off-82-dur-168-hours-asc---427700000`, conditional on season 277 being the client's runtime season and the profile using the normal timed mode. No live server read has occurred in this build.

Final version **0.7.0 remains blocked** pending an authorized successful Prestige read, independent score/rank and pagination verification, and cross-platform release CI. No GitHub or PyPI publication has been performed.
