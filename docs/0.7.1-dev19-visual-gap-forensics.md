## Typed use, no I/O

```python
from csr2cdn import analyze_visual_gaps

gaps = analyze_visual_gaps(snapshot, visual_library)
print(gaps.paint.present)
print(gaps.paint.resolved)
print(gaps.paint.library_id_missing)
print(gaps.wheel.join_unverified)
print(gaps.decal_number_color.palette_id_overlap)
print(gaps.as_dict())  # privacy-safe counts, no source values
```

The report includes every supported appearance slot (including absent ones),
with `.unresolved` equal to `.present - .resolved`. A `palette_id_overlap`
means only that the *integer* also exists in the standalone color library;
never treat it as the name, even if it matches a visible UI color. Rim-name
overlap is equally non-authoritative. Raw wheel strings are suppressed.

If necessary for a **future separately approved** authenticated bulk test,
`--show-unmatched-visual-ids` adds a bounded list of **distinct numeric
unmatched IDs and their occurrence counts**, without a member/car association.
It requires a supplied visual library and cannot be accidentally enabled by
`--show-members`. It does not change the four existing read requests.
Do not publish raw optional-ID reports without reviewing them.
