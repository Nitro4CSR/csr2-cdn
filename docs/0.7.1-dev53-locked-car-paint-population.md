# Dev53 — car-local paint-list population (offline, APK 6.8.0)

Dev53 investigates how a car-specific `CarVisuals.CarPaintIDs` sequence can be
augmented, without substituting a global paint library's iteration order.

## New native witness

The exact CRC-independent SHA-256-pinned ARM64 method bodies at
`0x3818cdc` (`CarVisuals.AddAftermarketPaintsToCar`) and `0x380decc`
(`CarVisuals.get_LockedCustomisationData`) were identified from the managed
IL2CPP method index and ARM64 ELF method pointer relocation table. The
`AddAftermarketPaintsToCar` body calls the locked-customisation getter from
two places (`0x3818d58`, `0x3818d8c`); inside its loop it reads integer
entries, checks whether a matching value is already present in the car-local
array at `0x70`, and can append a value that is missing. This is a native
algorithm witness for **additional entries**, not a complete constructor trace
or a runtime array dump. The observed list order is not necessarily the
standard `CarPaintLibrary` order.

The body is pinned to the supplied CSR2 6.8.0 APK. Any different APK body
fails closed. The tool avoids interpreting a numeric `15` as a globally
indexed paint label. There is no new accepted mapping and no read of live
roster or client runtime state.

## Offline cache scope

`endpoint-cache.zip` includes the two current paint libraries, and 275
metadata blocks, but does not supply verified **per-car ordered runtime
paint-ID arrays**. Dev53 reads only five allowlisted, locally cached JSON
metadata blocks plus public CDN descriptors. It checks metadata SHA-256
against the cache manifest. It does **not** open the cached private crew or
leaderboard records. Absence of a proven schema is not proof that no such
source exists elsewhere in the APK or CDN.

The cached metadata's original database version is not established by the
presence of public library assets from database 34011.

## Run

```bash
python -m csr2cdn.dev53_paint_population \
    --apk CSR2_6.8.0.apk \
    --cache-zip endpoint-cache.zip \
    --output dev53-paint-population-evidence.json
```

Without `--cache-zip`, the native APK witness runs independently.
The command makes no network or gameplay requests. Reports contain method
addresses, SHA-256 and metadata counts only, not roster values or car keys.
It refuses output overwrite, symlinked input and wrong native binary hashes.
