# Dev4 — exact HUB CarData vehicle cross-reference (offline)

## Evidence and boundaries

The pre-existing HUB client exposes `HubCDN.get_text_data("CarData")` from
`TextData/CarData.json`. The publicly archived file at
`https://github.com/Nitro4CSR/CSR2-HUB/blob/main/TextData/CarData.json`
has a list of records keyed by `DBName` (observed 1,343 records when
inspected on October 17, 2026). Each record includes `Tier`, `Star`, `isEV`,
plus third-party narrative fields that the decoder intentionally ignores.
Community metadata is *not* signed 6.8.0 native data; completeness and the
meaning of optional catalogue counters are unverified. Local fixtures can
be passed without accessing the network at all.

## Contract

`VehicleCatalog.from_car_data(list)` validates up to 10,000 records and unique
exact `DBName` strings. Invalid identifiers and ambiguous duplicates fail.
`match(current_car)` is case-sensitive and does not strip or normalize
identifiers, derive a display name, or make suggestions.
`resolve_vehicle_report(snapshot, catalogue)` returns only coverage counters by
default. If the user opts into `show_members=True`, it includes catalog-record
candidates in roster order but never account IDs, license plates, or free-text
HUB descriptions. That list must be treated as private per-member data.

The bulk probe accepts `--car-catalog-json PATH`, alongside existing offline
fixtures or `--execute`. The path is read only when the run actually performs
its decoded analysis; dry runs do not touch it. The local JSON size is bounded
by the bulk probe's 8 MiB input cap. A live bulk run still uses only the same
four previously defined game reads. The source catalogue is never fetched
or refreshed by this path. It must be supplied/updated by the operator.

## Intentionally unresolved

- Names for `car_paint_id`, `car_livery_id`, wheels, decals, or gacha IDs.
- Localized UI names for model DB keys and current source freshness.
- Car screenshots; HUB snapshot URLs are not evidence of asset availability.
- Any conclusion that an unmatched car or customization is absent in-game.

The next bulk test can measure coverage. We can keep, improve, or remove the
lookup based on that evidence without changing published 0.7.0.
