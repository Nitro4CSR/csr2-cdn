# Interior zone display attributes — 0.7.1.dev13

Native evidence: the uploaded `CarInteriorLibrary.ASTC.1139` has two separate
serialized fields, `Zone1Name` and `Zone2Name` per interior ID. The Dev12
native decoder preserves both in `VisualCodeName.names=(zone1, zone2)`.

Dev13 exposes them via `vehicle.visuals.interior.name.zone1` and `.zone2`.
The existing `.name` still compares, formats and serializes as the first zone
name, and `.names` remains the ordered tuple. Unverified/manual one-name
records produce `.zone2 is None`; unbound IDs have `.name is None`.

The source asset is not redistributed. Android uses ASTC; other qualities
require separately validated inputs. Nothing in this change fetches assets
or invokes game services. The next two candidates in the uploaded 6.8.0
asset DB are `CarCalliperLibrary.ASTC.1004` and
`CarColorLibrary.ASTC.594`; URL accessibility has not been verified.
